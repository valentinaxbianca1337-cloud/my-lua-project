nyameeow.pink

Основной файл: nyameeow.pink.lua. Исправления сделаны в загруженной Lua,
DLL GameSense для этой версии не изменялась.

Что исправлено

- После одной временной ошибки билдер больше не блокируется до перезагрузки
  скрипта: прежние параметры освобождаются, затем выполняется повторная
  попытка с короткой паузой. Одинаковая ошибка не печатается каждый тик.
- Неудачная загрузка конфигурации снимает changing/defensive_changing/
  updating_aa и возвращает прежнее состояние. Результат false больше не
  считается успешной загрузкой только потому, что pcall не выбросил ошибку.
- Импорт состояний проверяется до изменения UI. Выбранные Team/State и
  фактически применяемый профиль совпадают. Неполный профиль получает
  значения по умолчанию вместо остатков от другого состояния.
- Общий снимок и снимок билдера сохраняются согласованно; отказ второго
  сохранения возвращает обе прежние строки.
- Исправлено владение нативными контролами после частичного отказа
  восстановления: параметры pitch/yaw/body не меняются местами в списке.
- Freestanding передаёт хоткею строковый режим Always on вместо boolean.
  При освобождении возвращается прежний режим; изменение клавиши самим
  пользователем сохраняется.
- Обновлены видимое название, футер, водяной знак, Discord и клантег.
  Скрытые старые идентификаторы UI оставлены для совместимости с CFG.

Настройки и совместимость

Новый файл пресетов: nyameeow.pink_presets.dat. Старые afterglow-пресеты
читаются и мигрируют; исходный старый файл не перезаписывается. Импорт
принимает nyameeow.pink_, afterglow_ и AGP1:. Каталог старых звуков
afterglow/sounds сохранён, чтобы не потерять уже установленные WAV.

Выгрузи прежний afterglow.lua перед загрузкой нового файла. Два скрипта
одновременно могут управлять одними и теми же нативными AA-контролами.
Нативный AA → Enabled должен оставаться включённым для работы билдера.

Размер

Исходник: 1 710 406 байт. Новый файл: около 1,45 МБ.
В исходнике модуль Manual Arrows занимает 391 377 байт, watermark_icons —
282 407 байт. В Modern находятся 122 PNG-кадра/слоя. Они сохранены;
длинные десятичные escape-строки перепакованы в стандартный Base64.
PNG-данные проверены побайтно и по CRC. Оптимизация не удаляет стили
стрелок и не меняет их изображение.

Иконка — ещё требуется файл

Новый портрет из сообщения пока не встроен: доступен его просмотр в чате,
но исходного PNG/WebP нет среди файлов. До получения файла сохранена
прежняя иконка. Она также перепакована без изменения изображения.

Углы и GameSense

Проверены обращения к нативным AA-контролам, типы значений и восстановление
настроек. Custom pitch ограничен -89..89, yaw нормализован в -180..180,
параметры Body yaw в билдере ограничены диапазоном -58..58. Старые значения
60 при импорте приводятся к 58.

Body yaw — входной параметр нативного меню; число в Lua не является
измерением серверной разницы между eye yaw и направлением тела. Движение,
анимация, нативные ограничения и остальные скрипты влияют на результат.
Доступный C++-проект содержит загрузчик и бинарный core, поэтому проверка
Lua/API не выдаётся за полный аудит восстановленного C++ anti-aim.
Fast Ladder и Drop Nades сохраняют свои временные изменения command-углов.
