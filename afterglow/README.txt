Afterglow — изменения от 22.11.2026

Основной файл: afterglow.lua. Это полная версия на основе последнего for_changes.lua,
а не отдельная надстройка. Иконка и библиотека кастомной вкладки сохранены.

Изменения:
- Удалены Custom Output, World Hitmarker, Second Scope FOV и GameSense Debug Panel:
  настройки, отрисовка и обработчики этих функций.
- Manual Arrows: добавлен CS2 из Emberlash_source / Angle arrow / Glow dot.
  Светящаяся точка перемещается между направлениями, оставляет короткий след,
  после отпускания Manual возвращается вниз и гаснет.
  Цвет активного состояния и цвет ожидания настраиваются отдельно.
- Manual Arrows: добавлен Modern из Emberlash_V3 / Pointers.
  Сохранены символы ∘ / ≺ / ≻ и смещение при прицеливании.
  Добавлено переднее направление в том же стиле. Цвет настраивается.
- Существующие Team Skeet и Custom сохранены. Arrow Offset работает со всеми стилями;
  у CS2 значение 42 соответствует исходному расстоянию Glow dot в 78 пикселей.
- Japanese в Crosshair Indicator заменён вариантом Aetheryx:
  оригинальные японские строки, цвета Manual, DT/HS, Fake Duck, damage override,
  плавное появление и смещение при прицеливании. Default сохранён.

Backtrack Record Fix:
Обнаружены и исправлены: проверка только префикса инструкции; частичное применение;
присвоение уже чужих патчей; безусловный откат динамического gap; лишние записи
одинаковых значений; отсутствие восстановления вне карты.
Теперь проверяются все байты каждого участка до записи. Записанные участки
учитываются отдельно; ошибка приводит к откату. Чужие изменения не перезаписываются.
Проверяется доступность страниц памяти, результат VirtualProtect, прочитанные после
записи байты и FlushInstructionCache. Отключение/выход с карты восстанавливает
собственные изменения, в том числе через paint_ui вне setup_command.

Важно для оценки результата: lagrecords.gamesense.txt — менеджер чтения и проверки
записей, а не подтверждение адресов и смысла патчей Backtrack Record Fix. Его
критерии валидности не доказывают, что увеличение лимитов в afterglow делает запись
доступной для попадания. Исходные адреса, MAX_MOVE и значения патчей сохранены;
подтвердить их соответствие вашей DLL и фактический эффект можно только в игре.
При несовпадении байтов Fix отключается с объяснением в консоли.
Публичный API не позволяет обещать попадания по невалидным серверным записям.

Проверено локально:
- Компиляция полного файла через LuaJIT без выполнения нативных хуков.
- 25 поведенческих проверок рендереров и управления патчами.
- Чтение/запись FFI на выделенном тестовом буфере с моделью системных вызовов:
  запрет доступа, VirtualProtect, отказ записи, сбой очистки кэша инструкций.
- Неизменность встроенной иконки и библиотек memory/custom_tab.
В настоящем клиенте GameSense файл здесь не запускался.

Установка: скачайте afterglow.lua, замените им прежнюю версию Afterglow и перезагрузите
скрипт. Одновременно две копии Afterglow не загружайте. Существующие зависимости
for_changes.lua (gamesense/pui, antiaim_funcs и остальные) по-прежнему нужны.
