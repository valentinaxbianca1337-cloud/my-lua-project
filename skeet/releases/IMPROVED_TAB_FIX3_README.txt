Improved UI fix 3 / 2026-11-23

Исправлена проверка, блокировавшая создание вкладки при различном порядке
Tabs и TabsArr. В исходном core порядок записи семантических слотов:
0,6,1,2,3,4,5,7,8. Эти списки не обязаны совпадать по индексам.
Теперь проверяются принадлежность указателей, родитель и индексы вкладок.
Остальные существующие иконки располагаются в исходном визуальном порядке,
запомненном по координатам; Improved с кисточкой добавляется под Rage.
Логические номера, native вектор и TabsArr не переставляются.
Legacy-проверки других UI-модулей сохраняют прежние ограничения.

Установка:
1. Полностью закрыть csgo.exe.
2. Распаковать Fix 3 в новую папку.
3. Запустить Launch_Improved.cmd. В консоли должна быть версия:
   Improved UI fix 3 / 2026-11-23
4. После запуска ядра открыть меню через Insert (проверка ждёт до 30 секунд).
5. improved-status.txt рядом с DLL: stage=5 означает создание вкладки.
   При stage=2 теперь указывается конкретная причина отклонения окна;
   custom_index в этом состоянии является кодом ошибки, а не индексом вкладки.

Проверено: 8 сочетаний структуры главного окна/головы цепочки/сторонней
Lua-вкладки/семантического lookup, 24 смены DPI в этих сценариях,
сохранение полного vtable (15/24/31), отказ для повреждённых родителя,
индекса, lookup и числа вкладок без выделения объектов.
Также прошли 784 проверки геометрии, 6000 native hit-test, 84 смены DPI
и 540 native вызовов отрисовки иконок. Fixture имеет контролируемые границы
constructors/allocator/renderer/отдельных callbacks. Игра и GPU не проверены.

Комплект: DLL, matching injector, исходники, ресурсы, отчёты. Legacy CS:GO x86.
Три панели Backtrack / Lag records / Extrapolation пока без новых игровых
настроек. Movement и Profiles в Improved отсутствуют.
Исходное игровое ядро и movement exports не менялись.
