Установка:
1. Полностью закрыть csgo.exe. Поверх уже загруженной DLL обновить нельзя.
2. Распаковать этот архив в НОВУЮ папку.
3. Запустить Launch_Improved.cmd. Загрузчик должен показать:
   Improved UI fix 2 / 2026-11-23
4. После запуска ядра открыть меню клавишей Insert. Загрузчик ждёт до 30 с.
5. Рядом с DLL появится improved-status.txt. stage=5 означает, что native
   вкладка создана. Если кисточки нет, этот файл нужен для дальнейшего разбора.
