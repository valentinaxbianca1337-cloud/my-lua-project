Aim Recovery 4 — 25.11.2026

Восстановлен исходный путь обработки записей/поз и генерации точек Skeet.
Наш record installer полностью убран из production include/call graph:
пять перехватов выбора/getter/apply не устанавливаются, промежуточные полные
poses и сдвиги матриц Extrapolation не подставляются в процесс стрельбы.
Custom Hitscan уже отсутствует. Исходный embedded core сохранён побайтово.

Это откат экспериментальных изменений, не перенос другого resolver. В native
меню Improved собственные флажки Backtrack/Consistent pose/Limit records/
Extrapolation серые намеренно: runtime отсутствует. Штатные возможности и
backtrack самого GameSense остаются внутри оригинального ядра. Нет увеличения
окна сервера, отключения hitchance/урона либо подмены причины промаха.

Аудит старой версии
В Records3 воспроизведён дефект признака ownership: при совпадении context,
но другой цели, apply callback мог выбрать legacy-ветку, а wrapper затем
отклонял даже заданный успешный native result по состоянию предыдущей сессии.
Это воспроизведение на контролируемой границе native result, не доказательство
того, что именно так произошёл конкретный пользовательский промах.
В Recovery соответствующий installer/обёртка вообще не включены в production.
Экспериментальный исходник сохранён только для аудита/отдельных старых fixtures.

Кроме того, Consistent pose раньше совмещался с построением промежуточной
полной позы, а Extrapolation — с переносом уже существующих матриц. Проверки
на стенде показывали математическую согласованность, не точность серверной
анимации. Эти допущения в данной восстановительной версии не применяются.

Lua
Вместе приложена afterglow_aim_recovery.lua. В ней заблокированы старые
нативные aim/record/DT/movement фиксы и изменения tickbase/packet policy.
Обычный builder, оформление и логгер сохранены в исходнике; подробный список
отключённых возможностей и предел тестирования — AFTERGLOW_RECOVERY_README.txt.
Отдельный NL movement adapter и AI Peek в первом сравнении не загружать.
Чистые movement exports внутри DLL сами по себе в команды не вмешиваются.

Установка
Сначала снять автозагрузку старых Lua, затем полностью закрыть игру; использовать skeet.dll и injector.exe только из этого
комплекта. Первый короткий запуск без Lua, затем только новая recovery-Lua
вместо старой. Старые изменения могут оставаться в памяти до перезапуска.
Старые релизы в GitHub сохранены для отката; конфиги на новые HC/damage числа
автоматически не переписываются.

Проверки
Оригинальный resource SHA256 и шесть native sites проверены. Production include
 graph не достигает record/hitscan runtime installer. UI resize/DPI/иконки,
структура Windows x86/ресурс и pure movement exports проверены в fixtures.
Lua компилируется; слой запрета модулей отдельно проверен LuaJIT 2.1.
DLL entry, injector, сама игра, новый FPS/hit rate и все ветки полного Afterglow
в этой среде не выполнялись. Наличие correction/unknown и prediction error
в старом логе не позволяет обещать их полное исчезновение в новой сборке.
